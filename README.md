# Salary Tax & Expense Manager

Offline Flutter app for Indian salary calculations and expense tracking.

## Run

1. Install Flutter 3.22 or later and an Android SDK.
2. From this folder run `flutter pub get`.
3. Run on a device or emulator with `flutter run`.
4. Build a release APK with `flutter build apk --release`.

Data is stored locally in SQLite. Theme and budget use shared preferences. Notifications are scheduled locally and require notification permission on Android 13+.
